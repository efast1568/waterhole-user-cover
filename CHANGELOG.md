# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-11-02

### Added

- User profile cover image upload, positioning, and removal.
- Permission-based access to user cover management.
- Administrator cover management.
- Generated background colors for profiles without a cover image.
- Image validation for JPEG, PNG, and WebP uploads.
- Image downscaling and WebP encoding.
- Storage through the configured Waterhole uploads disk.

### Compatibility

- Waterhole Core 0.7 and 0.8 tested.
